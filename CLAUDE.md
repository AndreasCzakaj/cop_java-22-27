# CoP Java: Java Features in versions 22 - 27

3h training course to make developers familiar with Java features that were introduced in versions 22 - 27.
In addition, selected other useful features are shown.

This repo is a collection of exercises with Java files in their initial state and configuration ready to start coding.
Each exercise is in a separate package, and the exercise instructions are inside the Java files as markdown comments (feature introduced in Java 23).
In all but 1 case, there are JUnit + AssertJ tests. 
=> Developers are to implement the exercises. If the tests pass, the exercise is considered solved.

Solutions can be found in the `solution` branch.

# Selected topics

1. Compact source files and instance main
2. AssertJ object comparison with `useRecusiveComparison`
3. Flexible constructor bodies
4. Primitive patterns + _
5. Structured Concurrency + Scoped Value
6. Stream Gatherers
